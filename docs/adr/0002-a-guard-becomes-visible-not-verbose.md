# A guard that code cannot check becomes visible, never another instruction

Three of this engine's guards were enforced by code: a gauge that counted
figures and named instances from the person's own words, anchors verified
against the one source each names with anything under ten folded characters
refused, and a forced tool call that made the sheet be a sheet rather than one
more interview question. The floor runs none of that. A guard restated as an
instruction is read by the same model it is meant to catch, so each one is
converted into something the person can see instead: the sheet prints the
quote beside every bullet with its source named, the gauge lists the facts it
counted rather than announcing a number, and the ten character rule is written
out in words.

## Consequences

The output is more verbose on purpose, and a contributor who trims the repeated
quotes as redundant removes the enforcement rather than tidying it. That is why
this is written down.

The payoff was not planned and is worth naming: a guard made visible is a guard
made greppable from outside. `scripts/eval.py` can assert on a transcript that
a sheet appeared, that every bullet carries a quoted string and that both
angles quote, without knowing anything about the model that produced it.
